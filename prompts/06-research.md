# Этап 06 — исследование

Координатор: ChatGPT. Исполнение скриптов: Claude Code или явно назначенный Codex.
Аудитор методики и эталонов: Gemini. Не выдавай смену роли одной модели
за фактическую независимую проверку другой моделью.

Прочитай требования, docs/RESEARCH_PLAN.md, dataset, corpus manifest и configs.
Сначала проверь эталоны, разделение dev/test и способы расчёта метрик.
Запиши гипотезы и порядок сравнений до запуска. Исправь ошибки методики.

Проводить сравнения по одному фактору, фиксируя остальные и бюджет контекста.
Начать с retrieval-only, затем сравнить генерацию для кандидатов. Не делать
весь декартов перебор. Соблюдать квоты; не включать платный режим автоматически.
Выбирать параметры на dev. Финальный набор использовать после выбора конфигурации.

Сохранить config, corpus snapshot, dataset version, git SHA, model IDs,
prompt versions, retrieval outputs, answers, scores, latency, usage, errors
и Langfuse run/trace IDs. Не скрывать failed requests и fallback.
Сравнивать chunking по документам/секциям/размеченным evidence, не по нестабильным IDs.

Подготовить lab1/experiments/report.md с реальными таблицами, ограничениями,
неудачными случаями и объяснением выбора. Экспортировать доказательства из Langfuse.
Независимый аудитор проверяет соответствие таблиц сырым данным.
Обновить handoff и предоставить студенту объяснение каждого сравнения.
