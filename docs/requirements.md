## Легенда статуса

| Код | Значение |
|---|---|
| **О** | Обязательно по тексту задания («необходимо», «обязательной частью», «должна») |
| **П** | Обязательно по словам преподавателя (Langfuse, промпты, реальные API LLM/embeddings, векторы) |
| **Р** | Рекомендация методички («рекомендуется», «желательно», «например») — можно заменить с обоснованием |
| **Н** | Наше дополнительное проектное решение; не требование курса |

Колонка «Статус» в конце строки: `planned` — пока ничего не сделано. Ни одно требование ещё не выполнено.
