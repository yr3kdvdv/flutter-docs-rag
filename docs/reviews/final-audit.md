## Подтверждённые замечания

### A1 · P1 · Метаданные оценки могут указывать снимок другой коллекции

`Runtime.run_metadata()` читает общий манифест по `corpus.name`. Коллекции
Qdrant при том же имени корпуса раздельны по модели и стратегии chunking.
Оценка сравнивает датасет с SHA общего манифеста. Поэтому после построения
второй коллекции на другом снимке первая коллекция продолжает обслуживать
старое содержимое, а её метаданные отражают новый снимок. В офлайн-сценарии
с двумя снимками и настоящим embedded Qdrant `ask` вернул контекст снимка A
с метаданными B. `run_evaluation` отклонил разметку для A и принял разметку
для B, обработав одну запись на индексе A. В сохранённом финальном индексе
этапа 06 все 2694 точки при проверке соответствовали ожидаемому снимку.
[Метаданные runtime](../../lab1/src/flutter_rag/pipeline.py#L100) ·
[Имя коллекции](../../lab1/src/flutter_rag/runconfig.py#L126) ·
[Проверка оценки](../../lab1/src/flutter_rag/evaluation/runner.py#L135)

Минимальное исправление — хранить подтверждённый снимок для конкретной
коллекции и обновлять его только после полного успешного ingest. До оценки
сверять его с датасетом и закреплённым SHA конфигурации. Проверить два
снимка под одним именем корпуса и прерывание ingest.

### A2 · P2 · Маркеры в тексте могут расходиться со списком источников

Валидация ограничивает структурированный список `sources` номерами из
контекста, но сохраняет исходный текст и статус `answered`. В офлайн-сценарии
LLM-заглушка вернула `Sizes go up [99].` и `citations=[99]`. Приложение
вернуло этот текст, пустой список источников и два предупреждения.
Gemini обнаружил обратное расхождение в `test-006`, `test-014` и
`dev-002`. Список источников содержит цитату, которой в тексте нет,
а предупреждения отсутствуют. В сохранённом финальном прогоне
структурированные источники присутствуют у всех 24 ответов.
[Финальные ответы](../../lab1/experiments/runs/s06-final-test/raw.jsonl) ·
[Валидация](../../lab1/src/flutter_rag/pipeline.py#L513) ·
[Требования к ответу](../../lab1/prompts/answer/v1.2.md)

Минимальное исправление — проверять ссылки в тексте вместе с полем
`citations`, учитывать номера внутри блоков кода как код и явно обрабатывать
случай, когда ни одна цитата не подтверждена. Проверить результат через CLI/API.

### A3 · P2 · Английские вопросы получали ответ по-русски без предупреждения

В финальном прогоне `test-001` и `test-007` размечены как английские, а ответы
написаны по-русски. У обоих `warnings=[]`. Judge дал `test-001` 5/5 по обеим
шкалам, так что показатель 21/24 по judge сохраняется и не измеряет
соблюдение языка. Код проверяет предупреждение только для вопроса на
русском. В `dev` Gemini подтвердил ещё три таких случая у выбранной
модели с `answer/v1.2` и два с `answer/v2`. Gemini присвоил замечанию P1
из-за наблюдаемого сбоя на пользовательских вопросах. В итоговом списке
это P2, поскольку отказ на нужном языке работает, а исследовательский
вывод по заданным метрикам воспроизводится.
[Финальные ответы](../../lab1/experiments/runs/s06-final-test/raw.jsonl) ·
[Dev-ответы](../../lab1/experiments/runs/s06-gen-flash-v12-dev/raw.jsonl) ·
[Проверка языка](../../lab1/src/flutter_rag/pipeline.py#L525)

Минимальное исправление — распознавать несовпадение для обоих поддерживаемых
языков, игнорируя фрагменты кода при проверке, и проверять качество на dev
или новых демонстрационных вопросах. Для отчёта явно указать, что judge
оценивает корректность и обоснованность.

### A4 · P2 · В README нет полного сценария воспроизведения выбранного конфига

Команды ingest, ask и serve по умолчанию работают с восьмистраничным
срезом. Пример оценки использует другой индекс, `configs/full.yaml`, а
финальный вариант имеет третью конфигурацию, `s06-final.yaml`. В чистом
архиве есть манифесты, но нет сырого корпуса и Qdrant. Если выполнить
только показанный ingest, индекс для оценки на полном корпусе не появится.
README содержит ссылки на архитектуру и результаты, но ему ещё нужны
отдельные инструкции по конфигурации, API и тестированию из общего
требования к оформлению. [README](../../lab1/README.md#команды) ·
[Значения CLI](../../lab1/src/flutter_rag/cli.py#L28) ·
[Финальный конфиг](../../lab1/experiments/configs/s06-final.yaml)

Минимальное исправление — добавить блок команд с одним явным конфигом от
ingest до ask/serve, команды проверки dev и офлайн-пересчёта результатов,
таблицу переменных и статусов API, замечания о квотах и восстановлении.

### A5 · P2 · Ошибка работающего сетевого Qdrant выходит из API как HTTP 500

Gemini обнаружил, что `open_qdrant` преобразует ошибку только при первом
подключении. Операции `VectorStore` могут выбросить исключение клиента,
которое не обрабатывается на путях `/ready` и `/ask`. После инъекции
`ResponseHandlingException` с причиной `httpx.ConnectError` оба
маршрута вернули HTTP 500 в FastAPI TestClient.
[Хранилище](../../lab1/src/flutter_rag/vectorstore/__init__.py#L55) ·
[Обработка запросов](../../lab1/src/flutter_rag/api/__init__.py#L45)

Минимальное исправление — преобразовать сетевые ошибки операций
Qdrant в `UpstreamError`, вернуть 503 из `/ready` и проверить API и CLI
при отказе после подключения.

### A6 · P3 · Дополнительные замечания к промптам, метрикам и документации

- `Prompt.render_user` заменяет плейсхолдеры последовательно.
  Офлайн-проверка показала, что литерал `{question}` из выдержки
  заменяется текстом запроса. Использовать однопроходную подстановку
  по примеру рендера промпта судьи.
  [Рендерер ответа](../../lab1/src/flutter_rag/generation/__init__.py#L36) ·
  [Рендерер judge](../../lab1/src/flutter_rag/evaluation/judge.py#L78)
- Судья получает полный пользовательский промпт генератора, включая
  повтор вопроса внутри выдержек. Агрегатор judge также включает оценку
  ложного ответа на вопрос без эталонного ответа. В синтетической
  проверке это изменило среднюю с 5/5 на 3/5. Следует передавать судье
  только выдержки и явно согласовать знаменатель с исследовательским
  отчётом. В сохранённом финальном прогоне все шесть вопросов без ответа
  получили отказ, поэтому состав рассчитанной выборки прежний.
  [Вызов судьи](../../lab1/src/flutter_rag/evaluation/runner.py#L399) ·
  [Агрегатор](../../lab1/src/flutter_rag/evaluation/metrics.py#L188)
- Корневой README ссылается на состояние этапа 01, а вводный текст
  матрицы требований утверждает, что этапы ещё не выполнены. Обновить
  обе страницы вместе с документацией запуска.
  [Корневой README](../../README.md#L5) · [Матрица требований](../requirements.md#L15)

Gemini также предложил сделать лимиты генератора и судьи настраиваемыми.
Действующий предел 12 RPM общий для моделей. По сохранённому HTTP 429
Gemma нельзя установить, какой лимит вызвал сбой. Это предложение по
настройке.
[Лимитер генератора](../../lab1/src/flutter_rag/pipeline.py#L83) ·
[Лимитер judge](../../lab1/src/flutter_rag/evaluation/judge.py#L125)
