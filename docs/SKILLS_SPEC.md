# Спецификации будущих skills


Это спецификации будущих skills. Исполнитель создаёт и проверяет их в формате установленного клиента; наличие файла с названием skill само по себе не означает, что клиент его загрузил.

| Skill | Когда применять | Обязательный выход |
|---|---|---|
| requirements-to-issues | Новое требование | Issue, зависимости, критерии, evidence |
| flutter-corpus-ingestion | Изменение источника/парсинга | Manifest, diff корпуса, тест идемпотентности |
| rag-experiment | Проверка гипотезы | Config, реальные raw results, metrics, run IDs |
| langfuse-instrumentation | Изменение pipeline | Проверенная trace и версия prompt |
| independent-review | Готовый PR | Замечания с доказательствами и проверенным SHA |
| context-handoff | Конец задачи/смена агента | Полный handoff по контракту |
| defense-coach | Завершённый этап | Объяснение, вопросы, проверка понимания |

Каждый skill описывает входы, шаги, инструментальные проверки, выходы и границы. Общую методику хранить в одном месте, а инструкции клиентов сделать короткими адаптерами. Проверить загрузку skill отдельно в каждом клиенте. MCP использовать для доступа к инструментам; он не синхронизирует память разных ИИ автоматически.
